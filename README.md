# Replicad primitive model preview

This app creates box and cylinder solids in a browser worker with Replicad. Enter dimensions in millimetres and an optional centered through-hole diameter (0 means no hole), then select **Build preview** to inspect the actual generated geometry: drag to rotate, scroll or pinch to zoom. The preview reports the calculated solid volume in mm³. For example, a 40 × 40 × 20 mm box with a 10 mm hole has a volume of approximately 30,429.2 mm³. Rebuild the preview after changing dimensions. Older projects without a hole setting open with no hole. Save an editable `.replicad.json` project in My files, and create an STL or STEP model there. Open saved projects from the app or from Files. STL and STEP are exports, not editable project files. Upload a project using Files first.

This is a primitive generator with at most one vertical centered hole, not a full CAD editor: there is no CAD source editor, assemblies, or validation for manufacturing. The project format is specific to this app. The preview requires browser WebGL and is an inspection aid, not a manufacturing check. Independently verify exported geometry before manufacturing.

The app uses the shared account file service; temporary guest Linux files are separate. Browser storage syncs with the account server when available. It checks file versions and asks before replacing other files. Each window owns its worker and file subscription; closing or cancelling stops its worker. Existing unsaved parameter changes prompt before opening another project or closing the window.

Source entry: `index.mjs`; viewer: `preview.mjs`; worker: `workers/engine.mjs`; dependencies and build settings: `package.json`. Build with the shared public app builder, which bundles dependencies privately. See `docs/APP_UNIFICATION_PROGRESS.md` for current validation and remaining work.
